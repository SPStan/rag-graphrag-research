# ADR-0016: конфигурация проверки целевого API

Статус: целевая конфигурация принята; короткая генерация подтверждена 6 октября 2026. Структурированная генерация и benchmark не проверены.

## Контекст и выбор

В SPEC ранее планировался Qwen2.5-72B и BGE-M3. Куратор выдал OpenAI-совместимый LiteLLM endpoint с `iairlab/qwen3.8-27b`; BGE-M3 удалённо не предоставляется. Для основного сравнения выбираем один генератор Qwen3.8 через API и локальные BGE-M3 эмбеддинги для всех систем. Доступный также GPT-OSS-120B пока не включаем: второй генератор добавил бы фактор в сравнение и новые расходы. Ранее заявленный административный лимит 90 млн токенов снят, но пределы каждого эксперимента нужно задавать протоколом.

Для issue #8 принят один пакетный локальный запрос эмбеддингов, затем один короткий удалённый запрос. Вызовы последовательны, без retry. Токены локальной и удалённой частей учитываются отдельно. Проверка JSON Schema и масштабирование запросов вынесены за пределы этого smoke. Альтернатива использовать локальный 3B для основного исследования отвергнута: это другой генератор; прежние локальные результаты остаются диагностическими.

## Следствия и проверка

6 октября BGE-M3 вернул два вектора размерности 1024 и локальный usage. Первый короткий запрос к Qwen не дал текст в ожидаемом поле; его usage неизвестен. После этого пользователь отдельно поручил попытаться решить проблему самостоятельно, не обращаясь к куратору. По этому поручению проведена дополнительная ограниченная диагностика: top-level `enable_thinking=false` вернул 65 reasoning tokens, а `chat_template_kwargs: {enable_thinking: false}` вернул правильный короткий ответ и ноль reasoning tokens. Последний вариант закреплён как стандартный; итоговый smoke с cap 32 проверил эмбеддинги и генерацию вместе. Один промежуточный ответ не сохранился из-за отказа файловой системы; его usage также неизвестен. Всего было пять удалённых запросов, то есть больше одного из исходного issue; это не представляется как выполнение исходного ограничения. Результаты — [TARGET_API](../docs/TARGET_API.md). Короткий ответ не подтверждает работу reader или OpenIE.

Решение пересмотреть, если изменится доступная модель эмбеддингов, backend или эффект `chat_template_kwargs`. Перед затратной индексацией требуется отдельная успешная проверка структурированного extraction и сохранения per-response usage; короткий ответ её не заменяет.
