# ADR-0031: один inference-only сигнал и committed freeze

Статус: формула выбрана на tuning; оценка signal-check разрешена только после
коммита freeze/code. Научное согласование нового PR отдельно перед merge.

## Контекст и выбор

Issue21 требует один сигнал ошибки Dense EM=0 без gold на входе сигнала.
Доступны сохранённые убывающие Dense top-5 cosine scores на tuning300 обоих
датасетов. Выбран `u=-scores[0]`: меньшая похожесть предполагает больший риск.
Выбор по доступности/интерпретации, без сравнения вариантов по check AUROC.
Новые confidence/self-consistency запросы отвергнуты как ненужный расход;
logprobs не выдумываются. Порог не нужен для AUROC, каскад не запускается.

## Порядок и защита

Сначала code/tests и public freeze с source/code/metric/split hashes, затем
обычный коммит. Evaluation CLI проверяет Git blob/ancestor и текущие pins до
чтения labels; функция сигнала получает лишь tuple пяти scores. Target вычисляет
общий evaluator отдельно. Тuning300/check100/reserve100 не пересэмплируются.
Невалидные inputs останавливают расчёт; один класс явно даёт undefined AUROC.

ID/signal/target таблица private в .cache, никогда в публичном summary.
Public — только агрегаты/SHA/измеренное время/0 новых токенов и POST.
Не перезаписываются исходные runs, raw, plans или предыдущий output.
Сеть блокируется; выбор нового сигнала и flip направления после check запрещены.

## Последствия и проверка

История PR40 уже раскрыла контрольные scores; E3/oracle использовали весь S500.
Нельзя восстановить независимость коммитом или назвать результат чистым holdout.
Оценка описательная; отрицательный результат допустим. E6 не следует из одной
точечной AUROC автоматически, экономия здесь не измеряется.
Тесты проверяют gold isolation, freeze/code pins, private paths, pairwise AUROC,
ties/один класс, постоянный split и повторяемость без HTTP.
Изменение формулы/направления после check требует отдельного нового протокола,
а не молчаливой подмены этого результата.


Проверка после freeze41c2f1c: AUROC Mu0,585 / Hot0,441, по100 вопросов.
Два фиксированных пересчёта аналитически равны, новых POST/токенов0.
H1 для обоих наборов не подтвердилась; формула/направление сохранены.
Ограничение раскрытого контроля и научная карточка требуют отдельного принятия.
