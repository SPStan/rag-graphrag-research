## Порядок ближайших занятий

1. Первая фиксация стенда и размещение репозитория для просмотра руководителем.
2. Проверка файла-артефакта MLflow и сохранности mock-записей после перезапуска.
3. Скачивание исходных данных и разбор одного вопроса с подтверждающими пассажами.
4. Подвыборки, сохранение ID и тесты детерминизма и полноты корпуса.
5. Конспекты первых работ; формат результата и локальные тесты учёта стоимости.

Запрос доступов пока отложен по решению студента. До их получения выполняются независимые задачи. Календарь не служит основанием помечать невыполненный блок завершённым.

## Как фиксируем работу

- Одна задача: цель, критерий проверки, статус и связанный коммит/результат.
- Коммит после законченного изменения; минимум еженедельная фиксация по заданию. Одна задача может дать несколько коммитов.
- Новая история начинается с фактической первой фиксации. Прошлые даты не подделываются.
- Еженедельный апдейт: сделано, измерения, LLM-токены за неделю/всего, блокеры, следующие задачи.
- Полные датасеты, индексы и базы не коммитятся. Небольшие результаты перед добавлением проверяются на ключи и личные данные.
