# Данные локального MVP

Источник — подготовленные авторами HippoRAG 2 наборы [osunlp/HippoRAG_2](https://huggingface.co/datasets/osunlp/HippoRAG_2), ревизия `5ec05b38deecc3318bb432c69865959c56058990`. Старое имя `osunlp/HippoRAG_v2` перенаправляется на этот репозиторий. Размеры и SHA-256 всех шести файлов — в [sources.lock.json](../data/sources.lock.json).

## Повторить подготовку

Из корня проекта, Python 3.12 (дополнительных библиотек не требуется):

```powershell
.\.venv\Scripts\python.exe scripts/download_data.py
.\.venv\Scripts\python.exe data/make_subsample.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Повторная загрузка проверяет локальные файлы без сетевого запроса. Повторная подготовка сверяет результат и сохраняет одинаковые байты. Повреждённые исходники и отличающийся результат дают ошибку, а не скрытое обновление. Для новой версии протокола используем новые каталоги через `--output-dir`, `--ids-dir` и `--report`; прежние результаты не удаляем.

## Что означают файлы

- `data/raw/`: шесть исходных JSON, около 43 МБ, только локально.
- `data/processed/<dataset>/queries.json`: ID и вопрос. Это вход генерационного пайплайна.
- `data/processed/<dataset>/corpus.json`: общий корпус, ID/title/text; он доступен поиску.
- `data/processed/<dataset>/labels.json`: правильный ответ, допустимые алиасы и supporting IDs; только для оценки.
- `data/ids/`: публикуемые ID и происхождение выборки, без вопросов и текстов.

`labels.json` нельзя подмешивать в промпт модели. Поле idx в исходных данных не считаем глобальным идентификатором. Для MuSiQue сопоставляем paragraph_text, для HotpotQA собираем текст из предложений context. Совпадение проверяется по заголовку и полному тексту после нормализации пробелов. Обнаружен и объединён один канонический дубликат MuSiQue.

## Один понятный пример

В исходном `musique.json` первый вопрос имеет ID `2hop__13548_13529`: нужно определить, когда «Барселона» подписала футболиста, с которым сравнивали голы Месси в Кубке Испании. Один подтверждающий пассаж связывает сравнение с Марадоной, другой содержит дату его перехода. Эталон — июнь 1982 года. Поиск должен найти оба факта, а reader — соединить их. Это разбор источника, не результат работы модели и не обещание, что вопрос включён в первую сотню.

Наличие всех размеченных документов проверено автоматически, смысловую корректность всех 1000 аннотаций мы не проверяли. Ошибки исходника при анализе результатов нужно фиксировать, а не исправлять незаметно.

## Происхождение и условия данных

- MuSiQue: StonyBrookNLP, [исходный проект](https://github.com/StonyBrookNLP/musique), [лицензия CC BY 4.0](https://github.com/StonyBrookNLP/musique/blob/main/LICENSE).
- HotpotQA: Yang, Qi, Zhang et al., [страница набора и цитирование](https://hotpotqa.github.io/); авторы указывают CC BY-SA 4.0 для набора и обработанной Wikipedia.
- 2WikiMultiHopQA скачан как резерв исходного плана. Перед использованием и публикацией производных материалов отдельно проверим условия исходного набора и текстов; лицензия кода не приравнивается автоматически к лицензии всех данных.
- Использована упаковка HippoRAG 2; исходная HF-карточка указывает язык en, но не предоставляет единую лицензию на все объединённые наборы.

В этот репозиторий не включаются полные корпуса или преобразованные тексты. Ссылки на создателей сохраняются; ограничения исходных данных не изменяются этим проектом.
